About This Application

Name: Alina Kim

Course: Web Development / Angular

This project was created as part of an Angular laboratory assignment. The goal of the application is to demonstrate routing, services, and API communication using the JSONPlaceholder API.

The app allows users to browse albums, view album details, and explore photos.

Also, the developer of this application may or may not spend a questionable amount of time exploring Teyvat in Genshin Impact.

If this app had elemental powers, it would probably be Electro — because everything here runs on pure energy and questionable coding decisions.

Built with Angular, curiosity, and a little bit of anime motivation.
